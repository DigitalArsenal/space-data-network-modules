# propagator/sgp4-xp — vector provenance

`vectors.json` is generated by `vectors/tools/build-vectors.mjs` (`--check` fails on drift). It holds the Tier B
anchors `space-data-module conformance propagator` adjudicates for the propagator ABI (`plugin_propagate`).

## Source

| | |
| --- | --- |
| Element sets | The SGP4-XP (ephemeris type 4) sets of the test battery (`tests/lib/tle.mjs`, seed 20261012): LEO, sun-synchronous, MEO, GEO and a highly eccentric orbit |
| Expected states | The US Space Force library (`third_party/ussf-sgp4`, Sgp4Prop 9.1.1.0 XP build) through its own, unmodified Emscripten runtime, at 0, 90 and 1,440 minutes from each epoch, TEME km and km/s |
| Frame | TEME turned to Earth-fixed by GMST (IAU 1982), the conformance runner's own function, with the −ω × r velocity term; no polar motion, as the module |
| Record mapping | `bstar` carries BTERM and `meanMotionDdot` carries AGOM (m²/kg), as in the SDS `$OMM` for SGP4-XP |

The module wraps the same library, so the anchors check the adapter, the shim, the ABI record mapping, units and
frames. They do not check the SGP4-XP theory itself; no public reference outside the US Space Force exists.

## Tolerance

`fail <=> |observed − expected| > abs + rel · |expected|`

| Quantity | abs | rel | Why |
| --- | --- | --- | --- |
| position | 0.5 m | 0 | The ABI carries time as a double Julian date: near JD 2.46e6 one unit in the last place is about 40 µs, about 0.3 m along track in LEO. Measured: 2.3 cm. |
| velocity | 5e-4 m/s | 0 | The same time resolution. |
| time | 1e-9 day | 0 | |

## Invariants

None declared: SGP4-XP is a perturbed theory, so vis-viva and period closure do not hold.
